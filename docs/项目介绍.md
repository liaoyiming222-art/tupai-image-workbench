# 图派 · AI 批量作图工作台

GitHub 仓库： [liaoyiming222-art/tupai-image-workbench](https://github.com/liaoyiming222-art/tupai-image-workbench)

GitHub 中文简介：图派是一款基于 RunningHub 的本地 AI 批量作图工作台，支持需求文件夹导入、图片引用自动映射、模型切换、任务队列与生成结果自动归档。

图派将结构化作图需求转为可批量执行的图片生成任务。一个 RunningHub API Key 即可调用 Nano Banana 2 和 GPT Image 2.0，按需求分类自动匹配模型，也可手动切换。工具自动关联原图和参考图、转换提示词中的图片编号，并把生成结果保存回各需求目录的 AI 文件夹。支持分页缩略图、进度查看、失败恢复与结果版本管理。

图标以叠放的图片卡片表示批量任务，以星形表示 AI 生成，使用深绿与浅金配色。矢量图位于 public/icon.svg，同时用于应用标识和浏览器图标。

维护者：liaoyiming222-art。需求目录格式、模型接入方式和使用步骤详见仓库 README。
