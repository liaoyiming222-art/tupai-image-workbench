1. 从仓库提取上述拍摄提交的干净 archive 到独立目录，按其 README 运行静态演示；使用独立浏览器标签页与独立本机端口。本次使用 1366×1000 桌面画幅；结果查看页为独立 1280×720 画幅。
2. 总览：状态选待执行，选中客厅 T002。详情：打开该任务，展开编号映射、发送提示词。保存无修改的完整截图，分别对应 `source/overview.png`、`source/mapping.png`。
3. 刷新重置独立演示；执行全部就绪，暂停新提交，待当前条模拟完成后打开运行记录。保留失败和排队，保存 `source/queue.png`。
4. 打开客厅 T002 最新完成详情，保存 `source/record.png`；打开其查看结果入口（living-result），保存 `source/result.png`。没有修改页面 DOM、运行时数据或计时逻辑。
5. `source/layout.json` 记录每个截图的裁切范围与排版位置；`source/build.mjs` 只裁切、等比排版、加来源图注并导出，未重画产品 UI。
6. 安装本目录 package.json 的开发依赖；设置 `PORTFOLIO_NODE_MODULES` 为该 node_modules 所在目录，运行 `node source/build.mjs`。Windows 默认使用系统微软雅黑；其他环境设置 `PORTFOLIO_FONT` 指定中文字体。构建会重新生成 manifest 的尺寸、格式和 SHA-256，并导出 checks 预览。素材没有本机绝对路径或外站图片热链依赖。
